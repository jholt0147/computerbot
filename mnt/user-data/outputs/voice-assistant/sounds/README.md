# Sound effects

Sound effects are optional and are **not included** in this repository.
Put your own audio files in this folder and the commands below will play them.
If a file is missing, the command still works; it just skips the sound.

| File               | Played by                             |
|--------------------|---------------------------------------|
| `redalert.mp3`     | "computer, red alert"                 |
| `selfdestruct.wav` | the self-destruct code phrase         |

Playback uses `mpv`, so any format mpv understands will work if you
rename it (or change the filename in `commands.py`).
